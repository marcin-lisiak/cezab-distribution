# Project Skills & Instructions - Cezab Distribution

Ten plik zawiera wytyczne i preferencje dotyczące rozwoju projektu Cezab Distribution. Jako mój asystent AI, powinieneś stosować się do poniższych zasad:

## Design & Aesthetics
- **Styl**: Nowoczesny, premium, "stunning first impression".
- **Kolory**: Unikaj generycznych kolorów. Stosuj harmonijne palety (HSL), eleganckie tryby ciemne/jasne.
- **Typografia**: Używaj nowoczesnych fontów (np. Google Fonts: Inter, Roboto, Outfit).
- **Interakcje**: Subtelne mikro-animacje, efekty hover, płynne przejścia.
- **Media**: Wysokiej jakości wideo (mix-blend-mode dla przezroczystości), optymalizacja pod kątem wydajności.

## Technical Rules
- **Struktura**: Czysty HTML, nowoczesny CSS (Vanilla), JavaScript bez zbędnych bibliotek, chyba że wskazano inaczej.
- **Responsywność**: Mobile-first, perfekcyjne dopasowanie do wszystkich ekranów.
- **SEO**: Semantyczny HTML, poprawne tagi h1-h6, meta opisy.

## Specific Patterns
- **Video Hero**: Integracja wideo z tłem przy użyciu `mix-blend-mode: darken` (dla jasnych motywów) lub odpowiednich masek.
- **Components**: Modułowa struktura kodu CSS i JS.
